# 🏠 House Price Prediction using Machine Learning

## 📌 Project Overview

This House Price Prediction project was developed as a **Major Internship Project** during my internship at **Aenexz Tech Pvt. Ltd.** under the role of **Data Science & Data Analytics Intern**.

The goal of this project is to predict house prices accurately using Machine Learning techniques based on important housing features such as area, bedrooms, bathrooms, parking, furnishing status, and other property-related factors.

This project helped me gain practical experience in Data Cleaning, Data Visualization, Regression Modeling, and Model Performance Evaluation.

---

## 🎯 Objective

The main objective of this project is to build a Machine Learning model that can estimate house prices based on historical housing data and identify which factors most influence property pricing.

---

- Jupyter Notebook

## 📂 Dataset Features

The dataset includes the following important features:

- Area
- Number of Bedrooms
- Number of Bathrooms
- Number of Stories
- Main Road Access
- Guest Room
- Basement
- Hot Water Heating
- Air Conditioning
- Parking Availability
- Preferred Area
- Furnishing Status
- Price (Target Variable)

---

## ⚙️ Project Workflow

### 1. Data Collection

Imported the housing dataset using Pandas and examined the structure of the data.

### 2. Data Cleaning

- Removed duplicate records
- Checked missing values
- Handled null values
- Verified data types
- Encoded categorical variables into numerical values

### 3. Exploratory Data Analysis (EDA)

Performed data visualization using:

- Correlation Heatmap
- Scatter Plots
- Distribution Plots
- Feature Relationship Analysis

This helped in understanding the relationship between independent variables and house prices.

### 4. Feature Selection

Selected the most important features affecting house prices for model training.

### 5. Model Building

Implemented and trained:

- Linear Regression
- Multiple Linear Regression

### 6. Model Evaluation

Compared models using:

- MAE (Mean Absolute Error)
- RMSE (Root Mean Square Error)
- R² Score

### 7. Result Comparison

Visualized model performance using:

- Bar Charts
- Heatmaps

to identify the better-performing model.

---

## 📊 Model Performance

The models were compared based on prediction accuracy and error reduction.

### Evaluation Metrics Used:

- Lower MAE → Better Accuracy
- Lower RMSE → Better Prediction Quality
- Higher R² Score → Better Model Performance

Multiple Linear Regression showed better performance compared to basic Linear Regression.
